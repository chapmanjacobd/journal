I've made a few attempts over the years but this week AI helped me over the hump transitioning from X11 to Wayland and I'm at the point where I finally feel comfortable only using Wayland from now on.

You can see some of the recent changes here: chapmanjacobd/computer

One of the neat ideas that I had this week is this git.edit command. It provides the same interface of git add --patch but for existing commits. It's really handy! It's probably imperfect so only use it if you're comfortable digging yourself out of the reflog but it works for me.

Another thing which might be interesting (though I rarely use it as I usually do git am on a clean worktree) is git.applyhead. It uses git commit-tree and git update-ref to apply a patch under a dirty worktree.

A couple other recent things that I'm happy with are CLI helpers for installing/fixing/running Windows games in WINE: wine.game, wine.game.add, wine.dxvk. It just automates a lot of clicking around and I no longer feel panic at having to open a GUI or remember the correct WINE prefix to find and launch a game.
