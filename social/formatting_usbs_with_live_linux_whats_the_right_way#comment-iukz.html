This creates a new GPT partition table with a linux partition:

sudo sgdisk --zap-all -n 0:0:0 -t 0:8300 /dev/sdX

Then you can do mkfs on /dev/sdX1.

You could also do sudo wipefs -a /dev/sdX to clear the device but the above --zap-all already includes this step. If you have sgdisk you don't really need wipefs.

If you want a bootable USB just do:

sudo dd bs=4M oflag=direct status=progress if=Fedora-KDE-Desktop-Live-44.iso of=/dev/sdX

And this should do all that you need to do for you as long as you used /dev/sdX and not /dev/sdX1.
